# CRIPTO IA · Radar 24/7

Servicio de análisis público de criptomonedas y memecoins con escaneo continuo en servidor.

- Backend Node.js sin claves API ni ejecución de órdenes.
- Análisis Binance Spot y DEX Screener; las colecciones DEX se basan en tokens perfilados/promocionados y no son exhaustivas.
- Clasifica **SEÑAL**, **VIGILAR** y **DESCARTAR** en función de condiciones matemáticas heurísticas.
- Historial persistido opcionalmente en `/data` si se monta volumen Railway.
- API: `/api/health`, `/api/results`, `/api/history`, `/api/scan`.

No garantiza aciertos, no es modelo ML entrenado ni sustituye auditoría de contratos o gestión de riesgo. Los niveles son orientativos. Servicio independiente; no modifica otros repositorios.
